    Discord capture
    
      
    
        Share a job link into a private Discord channel (from your phone, from WhatsApp, anywhere) and it
        shows up here in Wishlist with the details filled in. The app checks the channel every 15 seconds
        while open and catches up on anything posted while it was closed.
      
    

      
    
        How to set this up (one time, about five minutes)
        
      
          
    1. Go to discord.com/developers/applications and click New Application. Name it anything, e.g. “Job Inbox”.
      2. 
          
    2. In the left menu open Bot. Click Reset Token, copy the token, and paste it below. Treat it like a password.
      3. 
          
    3. Still on the Bot page, under Privileged Gateway Intents turn on Message Content Intent and save.
      4. 
          
    4. Open OAuth2 in the left menu. Under OAuth2 URL Generator tick the bot scope, then tick the permissions View Channels, Read Message History, and Add Reactions. Open the generated URL and invite the bot to a server you own (make a new private server if you don't have one).
      5. 
          
    5. In Discord, create or pick a channel for job links. Enable Developer Mode (User Settings → Advanced), then right-click the channel → Copy Channel ID and paste it below.
      6. 
          
    6. Click Test connection, then Save. Post a link in the channel; the bot reacts with ✅ once it has captured it.
